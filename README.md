# Escape

3D TPS 시점에서 좀비를 피해 탈출 아이템을 수집하는 **1인 개발 3D 서바이벌 탈출 게임**입니다. 🧟‍♂️🚪

## 🎯 프로젝트 소개

좀비가 배회하는 위험한 영역에서 숨겨진 5개의 EXIT 사인을 찾아 무사히 탈출하는 3인칭 슈팅(TPS) 생존 게임입니다. 조준·발사 사격 액션과 생존을 위한 자원 수집 미션을 결합하여 긴장감 있는 탈출 루프를 제공합니다.

* **장르 / 플랫폼**: 3D TPS 탈출 생존 / PC (싱글 플레이어)
* **팀원 구성**: 개인 프로젝트 (1인 개발)
* **진행 방식**: GitHub Desktop을 활용한 코드 및 버전 관리

## 👩🏻‍💻 담당 역할

기획부터 아트 에셋 수급, 프로그래밍 전반을 **1인 전담**하여 개발했습니다.

* **게임 기획 & 메커니즘**: TPS 사격·이동 조작, EXIT 사인 수집 판정 및 탈출/게임오버 조건 설계
* **프로그래밍**:
  * 3인칭 캐릭터 이동, 달리기, 조준 및 사격 로직 구현
  * static/dynamic 오브젝트 상호작용(V키 수집) 및 인게임 UI 상태 연동
* **아트 & 애니메이션**: 에셋 수급 및 생성형 AI 리소스 활용, 3D 캐릭터 리깅 및 애니메이션 적용

## 🎮 주요 게임 메카닉 & 조작법

* **조작 체계**:
  * **이동**: `WASD` / **달리기**: `Left Shift`
  * **조준 및 발사**: 마우스 우클릭 / 마우스 좌클릭
  * **상호작용**: `V` (EXIT 사인 수집)
* **핵심 목표**: 좀비의 추격을 피하며 맵 곳곳에 배치된 5개의 EXIT 사인을 모두 수집한 후 목적지로 탈출

## 🖥️ 사용 기술

- **Engine & Language**: Unity 3D, C#
- **VCS**: GitHub, GitHub Desktop

## 🌱 성장 경험 & 회고

- **첫 3D TPS 파이프라인 구축**: 3D 공간감 구성, 3인칭 카메라 조준 시스템, 유니티 3D 스크립팅 등 3D 슈팅 게임 제작 전반의 메커니즘을 성공적으로 습득했습니다.
- **3D 캐릭터 애니메이션 & 리깅 문제 해결 시도**: 3D 모델 리깅 과정에서 발생하는 물리/애니메이션 이슈를 경험하며, 3D 캐릭터 파이프라인에 대한 기술적 이해도를 한 단계 높였습니다.
- **1인 풀사이클 개발**: 기획부터 사격/수집 로직 구현까지 전체 프로세스를 혼자 완수하며 독립적인 문제 해결 능력과 전체 시스템 통제 역량을 다졌습니다.
